# AI Guides — Каталог гайдов по ИИ и монетизации

Веб-приложение и интерактивный каталог практических инструкций по монетизации нейросетей, маркетингу, маркетплейсам и Claude Code.

---

## 📁 Структура проекта

```
Funpay_guid/
├── index.html                  # Главная страница веб-приложения / каталога
├── README.md                   # Документация проекта
├── assets/                     # Статические ресурсы веб-интерфейса
│   ├── css/
│   │   └── style.css          # Стили оформления (дизайн-система)
│   ├── js/
│   │   ├── app.js             # Логика интерактивного каталога, фильтрация и полноэкранный ридер
│   │   └── guides-data.js     # База данных гайдов (метаданные и тексты)
│   └── images/
│       ├── ai_books_illustration.jpg  # 3D-иллюстрация в шапке
│       └── gui.png                    # Референсный макет
└── content/                    # Исходные файлы гайдов
    ├── md/                    # Гайды в формате Markdown (.md)
    │   ├── guide_01_kak_pisat_idealnyj_kod_cherez_ii.md
    │   └── ...
    └── txt/                    # Гайды в текстовом формате (.txt)
        ├── guide_01_kak_pisat_idealnyj_kod_cherez_ii.txt
        └── ...
```

---

## 🚀 Запуск и использование

1. **Веб-версия (Каталог):**  
   Откройте файл `index.html` в любом современном веб-браузере.
   
2. **Возможности:**
   - Фильтрация по тематическим категориям и наглядные блоки разделов.
   - Чтение полных текстов гайдов с интерактивным оглавлением и прогресс-баром.
   - Скачивание любого гайда в формате `.MD` или `.TXT`.
