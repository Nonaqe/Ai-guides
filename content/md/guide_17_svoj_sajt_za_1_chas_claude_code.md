# Свой сайт за 1 час с Claude Code - без код

## Зачем это нужно
Создание собственного веб-сайта традиционно ассоциируется либо со сложной разработкой и написанием кода, либо с ограничениями стандартных конструкторов сайтов. С помощью консольного ИИ-ассистента Claude Code человек без малейшего опыта программирования может создать современный, красивый и полностью адаптивный сайт (лендинг, визитку, портфолио) всего за 1 час. Вы общаетесь с ассистентом на обычном русском языке, говорите, что хотите видеть на странице, а ИИ самостоятельно генерирует HTML, CSS и JavaScript файлы, создает структуру и запускает локальный просмотр. Данный гайд содержит подробный пошаговый сценарий создания веб-сайта с нуля.

## Что внутри
* Пошаговая установка Claude Code на домашний компьютер за 3 минуты.
* Выбор идеи и подготовка текстового описания будущего сайта.
* Генерация каркаса веб-страницы (HTML) и современного стилизованного дизайна (CSS).
* Добавление интерактивности и форм обратной связи (JavaScript).
* Просмотр сайта в браузере и внесение правок простым языком.
* Инструкция по бесплатному выкладыванию готового сайта в интернет.

## Пошаговая инструкция

### Шаг 1. Подготовка и установка инструмента (5 минут)
Для создания сайта вам понадобятся только консоль и браузер.

1. **Установка на Windows через PowerShell:**
   Нажмите `Win + X`, откройте PowerShell и вставьте команду:
   `irm https://claude.ai/install.ps1 | iex`

2. **Создание папки для сайта:**
   Создайте на рабочем столе папку `my_website`, откройте в ней консоль и запустите утилиту:
   `claude`

---

### Шаг 2. Генерация первого каркаса веб-сайта (15 минут)
Отправьте в Claude Code детальное описание вашего будущего сайта.

Первичный промпт:
`Я хочу создать современный одностраничный сайт-лендинг (Landing Page) для услуги "Кофейня и пекарня свежей выпечки".
Сделай структуру:
1. Шапка (Header): Логотип, меню навигации, кнопка "Заказать".
2. Главный экран (Hero Section): Цепляющий заголовок, краткое описание, кнопка призыва к действию и красивый фоновый градиент.
3. Блок "Наши преимущества": 4 карточки с иконками.
4. Блок "Популярное меню": 6 позиций с названиями и ценами.
5. Форма обратной связи для бронирования столика.
6. Подвал (Footer): контакты и социальные сети.
Создай файлы index.html и styles.css. Используй современный минималистичный дизайн с красивыми шрифтами Google Fonts.`

---

### Шаг 3. Добавление интерактивности и мобильной адаптивности (15 минут)
После того как ИИ создаст базовые файлы, попросите его оживить сайт.

Второй промпт:
`Добавь в проект файл script.js.
Сделай:
1. Плавный скролл при клике на пункты меню.
2. Анимацию появления блоков при прокрутке страницы.
3. Валидацию формы бронирования столика: при отправке формы должно всплывать красивое сообщение "Спасибо! Мы перезвоним вам в течение 5 минут".
4. Убедись, что сайт идеально выглядит на экранах мобильных телефонов.`

---

### Шаг 4. Локальный просмотр и быстрые правки (15 минут)
1. Откройте файл `index.html` в вашем обычном веб-браузере (двойным кликом мыши).
2. Оцените внешний вид. Если вы хотите изменить цвет, текст или размер элементов, просто напишите об этом в Claude Code простыми словами:
   * *"Сделай главный цвет кнопки оранжевым вместо синего."*
   * *"Увеличь размер шрифта в заголовке и добавь тень под карточками."*

---

### Шаг 5. Бесплатная публикация сайта в интернете (10 минут)
Чтобы ваш сайт стал доступен всем пользователям в сети:
1. Запросите у Claude Code: *"Подскажи, как бесплатно выложить этот сайт на GitHub Pages или Vercel"*.
2. ИИ выведет пошаговую инструкцию по загрузке файлов в интернет без оплаты хостинга.

## Примеры

### Пример реального диалога с ИИ при правке дизайна
**Вы:** `Карточки товаров выглядят слишком скучно. Сделай так, чтобы при наведении курсора мыши карточка плавно приподнималась вверх и появлялась легкая тень.`

**Claude Code:** `Вношу изменения в styles.css. Добавлены эффекты transform: translateY(-5px) и box-shadow при состоянии :hover.`

**Результат:** Сайт мгновенно приобретает дорогой интерактивный вид уровня профессионального агентства.

## Частые ошибки и вопросы

**Вопрос 1: Нужны ли деньги на покупку программ или платных сервисов?**
*Ответ:* Нет. Все используемые инструменты, редактор и бесплатный хостинг для размещения сайта в сети являются абсолютно бесплатными.

**Вопрос 2: Что делать, если текст на странице отображается кракозябрами?**
*Ответ:* Напишите Claude Code: *"Убедись, что в файле index.html установлена кодировка UTF-8 в теге meta"*. ИИ моментально исправит это.

**Вопрос 3: Сможет ли сайт правильно открываться на смартфонах?**
*Ответ:* Да, в промпте изначально задается требование адаптивной верстки (Responsive Web Design), благодаря чему сайт автоматически подстраивается под экраны любых устройств.

**Вопрос 4: Как заменить стандартные картинки на реальные фото?**
*Ответ:* Поместите ваши фотографии в папку с сайтом (например, `photo.jpg`) и попросите Claude Code: *"Замени изображение в блоге Hero на файл photo.jpg"*.

**Вопрос 5: Сколько времени занимает создание сайта с нуля для новичка?**
*Ответ:* При использовании пошаговых промптов из этого гайда весь процесс от установки до работы готового сайта занимает ровно 45–60 минут.
