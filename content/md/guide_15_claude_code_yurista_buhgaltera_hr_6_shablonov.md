# Claude Code для юриста, бухгалтера и HR | 6 шаблонов

## Зачем это нужно
Документооборот юристов, бухгалтеров и специалистов по кадрам (HR) состоит из сотен типовых договоров, актов, накладных, резюме и регламентов. Проверка документов на соответствие закону, поиск некорректных формулировок и сведение кадровых отчетов вручную забирает до 60% рабочего времени этих специалистов. Способность Claude Code локально читать структуру файлов, находить противоречия и генерировать шаблоны делает его идеальным помощником для офисных и правовых департаментов. В данном гайде представлены 6 готовых практических сценариев и шаблонов применения Claude Code в работе юриста, бухгалтера и HR-специалиста.

## Что внутри
* Инструкция по быстрой установке и подготовке инструмента для профессионалов.
* Шаблон 1 (Юриспруденция): Экспресс-аудит договора и подсвечивание рискованных условий.
* Шаблон 2 (Юриспруденция): Генерация шаблона соглашения о конфиденциальности (NDA).
* Шаблон 3 (Бухгалтерия): Сверка счетов, актов и поиск расхождений в реестре.
* Шаблон 4 (Бухгалтерия): Составление пояснительной записки и учетных регламентов.
* Шаблон 5 (HR-сфера): Скоринг и сравнение резюме кандидатов под требования вакансии.
* Шаблон 6 (HR-сфера): Составление плана адаптации (Onboarding Plan) и профиля должности.

## Пошаговая инструкция

### Шаг 1. Быстрая установка инструмента
1. **Установка на Windows через PowerShell:**
   `irm https://claude.ai/install.ps1 | iex`
2. **Запуск утилиты в папке с документами:**
   Перейдите в папку с договорами или отчетами и введите `claude`.

---

### Шаг 2. 6 Практических сценариев и шаблонов запросов

#### Шаблон 1. Юристу: Глубокий аудит договора аренды/поставки на риски
Положите файл договора `contract_draft.txt` в папку.

Промпт для ИИ:
`Ты — главный юрисконсульт компании. Проведи правовую экспертизу договора contract_draft.txt.
Задачи:
1. Найди все условия, налагающие одностороннюю ответственность или несоразмерные штрафы на нашу компанию.
2. Проверь порядок расторжения договора и условия возврата аванса.
3. Составь протокол разногласий в виде таблицы [№ пункта, Текущая редакция, Предлагаемая редакция, Обоснование риска]. Сохрани в файл Protocol_Disagreements.md.`

#### Шаблон 2. Юристу: Генерация кастомного соглашения NDA
Промпт для ИИ:
`Составь двустороннее соглашение о неразглашении конфиденциальной информации (NDA) между ООО "Компания" и Исполнителем.
Требования:
- Срок действия конфиденциальности — 3 года после окончания работ.
- Штраф за каждый факт разглашения — 500 000 рублей.
- Учти передачу исходного кода и бизнес-показателей. Сохрани шаблон в NDA_Template.md.`

#### Шаблон 3. Бухгалтеру: Поиск расхождений в реестре первичных документов
Положите реестры `registry_invoices.csv` и `registry_acts.csv` в папку.

Промпт для ИИ:
`Прочитай файлы registry_invoices.csv и registry_acts.csv. Найди все номера счетов, по которым отсутствуют подписанные акты выполненных работ. Сформируй список недостающей первички для запроса у контрагентов в файле Missing_Docs.md.`

#### Шаблон 4. Бухгалтеру: Написание внутренней учетной политики
Промпт для ИИ:
`На основе требований законодательства сформируй раздел Учетной политики компании для целей бухучета по учету основных средств и малоценного оборудования. Используй четкие формулировки, разбитые по разделам. Сохрани в файл Accounting_Policy.md.`

#### Шаблон 5. HR: Автоматический скоринг 10 резюме кандидатов
Положите текстовые выгрузки резюме (`resume_1.txt`, `resume_2.txt` ...) и описание вакансии (`job_description.txt`) в папку.

Промпт для ИИ:
`Проанализируй все файлы резюме в папке и сравни их с требованиями из job_description.txt. 
Составь рейтинговую таблицу кандидатов по 10-балльной шкале. 
Укажи для каждого: [Имя, Балл соответствия, Главные сильные стороны, Чего не хватает]. Сохрани результат в Candidates_Rating.md.`

#### Шаблон 6. HR: Разработка профиля должности и тестового задания
Промпт для ИИ:
`Составь профиль должности "Ведущий менеджер по продажам B2B".
Включи: ключевые KPI, необходимые компетенции, структуру собеседования из 5 ситуационных вопросов и практическое тестовое задание для проверки навыков деловой переписки.`

## Примеры

### Пример 1. Составление протокола разногласий юристом за 3 минуты
**Ситуация:** Подрядчик прислал договор на 25 страниц с жесткими penalty-условиями.

**Действие:** Юрист запускает Claude Code с Шаблоном 1. Инструмент за 90 секунд вычитывает текст и формирует протокол разногласий с указанием 4 скрытых рискованных пунктов.

### Пример 2. Автоматическая подготовка отчета по кандидатам HR-департаментом
**Ситуация:** На вакансию откликнулись 30 человек.

**Действие:** HR-специалист сохраняет резюме в папку и применяет Шаблон 5. Claude Code сортирует резюме и выводит 3 лучших кандидатов для приглашения на интервью.

## Частые ошибки и вопросы

**Вопрос 1: Можно ли загружать в Claude Code персональные данные сотрудников и клиентов?**
*Ответ:* Перед обработкой кадровых или бухгалтерских документов рекомендуется обезличивать персональные данные (заменять реальные ФИО и паспорта на шаблоны `[Иванов И.И.]`) либо использовать локальные изолированные окружения.

**Вопрос 2: Заменяет ли Claude Code профессионального юриста или бухгалтера?**
*Ответ:* Нет, инструмент берет на себя рутину: первичную вычитку, подготовку черновиков и поиск совпадений. Финальное решение и правовая виза всегда остаются за квалифицированным специалистом.

**Вопрос 3: Как проверить, не пропустил ли ИИ важный пункт договора?**
*Ответ:* Формулируйте промпт максимально конкретно: указывайте, какие именно категории рисков (штрафы, подсудность, сроки, форс-мажор) инструмент должен искать в первую очередь.

**Вопрос 4: Какие форматы файлов лучше использовать для передачи текстов договоров?**
*Ответ:* Преобразуйте документы в текстовые форматы `.txt` или `.md`. Это обеспечивает идеальную точность считывания символов и структур.

**Вопрос 5: Сколько времени занимает подготовка отчета по 20 договорам?**
*Ответ:* С помощью Claude Code обработка папки из 20 договоров занимает около 3–5 минут вместо целого рабочего дня ручной вычитки.
