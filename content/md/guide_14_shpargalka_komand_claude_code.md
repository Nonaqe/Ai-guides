# Шпаргалка команд Claude Code | Не гугли больше

## Зачем это нужно
Постоянный поиск синтаксиса команд, флагов запуска и слэш-команд во внешней документации отнимает время и отвлекает разработчика от процесса решения задач. Использование консольного ассистента Claude Code становится максимально быстрой привычкой только тогда, когда все ключевые команды находятся перед глазами в виде единой компактной шпаргалки. Этот гайд представляет собой полный справочный навигатору по системным командам, горячим клавишам, встроенным слэш-командам и флагам CLI утилиты Claude Code с наглядными примерами применения.

## Что внутри
* Команды установки, обновления и проверки версии инструмента.
* Полный справочник встроенных слэш-команд терминала.
* Флаги командной строки (CLI) для запуска в разном окружении.
* Команды управления контекстным окном и памятью проекта.
* Горячие клавиши и навигация в интерфейсе терминала.
* Наглядные примеры комбинированного использования команд в реальных рабочих ситуациях.

## Пошаговая инструкция

### Блок 1. Команды установки и управления CLI

1. **Первичная установка в Windows PowerShell:**
   `irm https://claude.ai/install.ps1 | iex`

2. **Установка через менеджер пакетов npm (Node.js 22+):**
   `npm install -g @anthropic-ai/claude-code`

3. **Проверка установленной версии:**
   `claude --version`

4. **Запуск интерактивной сессии в текущей папке:**
   `claude`

5. **Запуск с выполнением разового промпта без входа в диалог:**
   `claude -p "Провери код на ошибки и напиши список"`

---

### Блок 2. Справочник слэш-команд сессии (Slash Commands)

Набирайте эти команды непосредственно внутри диалогового окна Claude Code:

* `/help` — Вызов справки по доступным командам и горячим клавишам.
* `/clear` — Полная очистка текущего контекста диалога (начало работы с чистого листа).
* `/compact` — Ужатие истории текущей сессии с сохранением ключевых технических выводов.
* `/memory` — Просмотр и редактирование автоматически накопленной памяти проекта.
* `/doctor` — Проверка состояния здоровья окружения, прав доступа и сетевых подключений.
* `/config` — Просмотр и изменение текущих настроек ассистента.
* `/bug` — Сообщить о найденной ошибке в работе утилиты разработчикам.
* `/cost` — Показать статистику использования токенов и текущие затраты на сессию.

---

### Блок 3. Горячие клавиши и управление в терминале

* `Ctrl + C` — Прервать текущую генерацию ответа или отменить выполняемую команду.
* `Ctrl + L` — Очистить экран терминала (без сброса контекста нейросети).
* `Up / Down (Стрелки)` — Навигация по истории предыдущих отправленных запросов.
* `Tab` — Автодополнение путей к файлам и названий команд.

## Примеры

### Пример 1. Экспресс-очистка контекста при переходе к новой задаче
**Ситуация:** Вы закончили отладку базы данных и переходите к верстке компонента. Чтобы старый контекст не путал нейросеть, используйте цепочку действий:

1. Введите команду сжатия или очистки:
   `/clear`
2. Напишите новый запрос:
   `Открой файл Header.tsx и добавь адаптивную кнопку меню для мобильных устройств.`

### Пример 2. Быстрый аудит затрат токенов в процессе длительной разработки
**Ситуация:** Вы работаете над рефакторингом крупного модуля уже 2 часа и хотите оценить расход ресурсов.

1. Отправьте команду:
   `/cost`
2. Получите аккуратную сводку: израсходовано токенов на ввод/вывод и итоговая стоимость текущей рабочей сессии.

## Частые ошибки и вопросы

**Вопрос 1: Что делать, если команда claude не распознается в консоли после установки?**
*Ответ:* Перезапустите окно терминала (PowerShell или CMD) или проверьте, добавлены ли пути глобальных пакетов Node.js/npm в системную переменную окружения `PATH`.

**Вопрос 2: В чем разница между командами /clear и /compact?**
*Ответ:* Команда `/clear` напрочь стирает всю историю общения текущей сессии (как новый диалог). Команда `/compact` сохраняет суть проделанной работы, архитектурные выводы и текущий статус задачи, но сжимает развернутые логи и промежуточные ответы.

**Вопрос 3: Запомнит ли Claude Code настройки из /memory после вызова /clear?**
*Ответ:* Да! Команда `/clear` очищает только оперативный контекст текущей беседы. Файл `CLAUDE.md` и блоки из авто-памяти (`/memory`) сохраняются и автоматически считываются заново при следующем запросе.

**Вопрос 4: Как запустить Claude Code в режиме одноразового выполнения скрипта в CI/CD?**
*Ответ:* Используйте ключ `-p` или `--print`: `claude -p "проверить код"`. В этом режиме утилита выполнит задачу, выведет результат в `stdout` и завершит процесс с соответствующим кодом выхода.

**Вопрос 5: Как быстро вызвать последнюю введенную команду?**
*Ответ:* Нажмите клавишу "Стрелка вверх" на клавиатуре в поле ввода терминала для прокрутки истории прошлых запросов.

Сохраните эту шпаргалку команд или держите ее открытой во второй вкладке во время работы. Освоение слэш-команд `/compact`, `/memory`, `/clear` и флага `-p` повышает скорость управления Claude Code в разы. Используйте правильные команды управления контекстом, и ваша разработка станет структурированной, быстрой и экономичной!
