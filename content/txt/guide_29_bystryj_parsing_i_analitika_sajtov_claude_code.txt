# Быстрый парсинг и аналитика сайтов через Claude Code

## Зачем это нужно
Разработчикам и аналитикам регулярно требуется собирать открытые данные с веб-сайтов: цены конкурентов, каталоги товаров, новостные сводки или биржевые котировки. Написание скриптов для сбора данных (веб-скрапинга) традиционно требует ручного изучения структуры HTML-страниц, обработки динамических подгрузок на JavaScript и вывода данных в CSV или базам данных. Способность Claude Code локально исполнять консольные команды, читать DOM-дерево и генерировать скрипты на Node.js или Python позволяет создать надежный парсер веб-страниц за считанные минуты. Этот гайд содержит пошаговую инструкцию по разработке безопасных парсеров данных через Claude Code.

## Что внутри
* Инструкция по развертыванию окружения для веб-парсинга на Python / Node.js.
* Запрос к Claude Code для анализа структуры HTML/JSON веб-страницы.
* Написание парсеров с использованием библиотеки BeautifulSoup / Playwright.
* Автоматическая обход задержек и обработка пагинации (перехода по страницам).
* Сохранение собранных данных в структурированные файлы CSV, JSON или SQLite.
* Разбор практического примера сбора цен товаров и анализа конкурентов.
* Ответы на частые вопросы по обходу защит, ротации заголовков и этике скрапинга.

## Пошаговая инструкция

### Шаг 1. Подготовка рабочей директории и окружения
Для создания скрипта выгрузки потребуется изолированная папка и библиотеки для HTTP-запросов.

1. **Создание директории и инсталляция Claude Code:**
   `mkdir site_parser && cd site_parser`
   `claude`

2. **Запрос к ИИ на подготовку виртуального окружения (Python):**
   `Создай виртуальное окружение venv и установи библиотеки requests, beautifulsoup4, pandas и playwright для безопасного парсинга сайтов.`

---

### Шаг 2. Написание асинхронного парсера страницы
Передайте Claude Code пример структуры HTML-кода целевой страницы или прямой URL для выгрузки.

Промпт для создания парсера HTML:
`Напиши скрипт на Python (parser.py) для сбора данных о товарах.\nТребования:\n1. Скрипт делает HTTP-запрос к странице каталога с помощью библиотеки requests.\n2. Парсит HTML-код с помощью BeautifulSoup.\n3. Извлекает из каждой карточки товара 4 поля: [Название товара, Текущая цена, Старая цена, Наличие (True/False)].\n4. Использует случайную задержку между запросами от 1 до 3 секунд (`time.sleep`) и ротацию заголовка User-Agent.\n5. Сохраняет результат в файл products.csv в кодировке utf-8-sig.`

---

### Шаг 3. Обработка динамических сайтов на JavaScript (Playwright)
Если сайт подгружает данные через AJAX или требует исполнения JavaScript-кода в браузере, попросите ИИ применить Playwright.

Промпт для динамического парсера:
`Напиши скрипт на Python с использованием Playwright (asyncio).\nСкрипт должен:\n1. Открыть браузер в безголовом режиме (headless=True).\n2. Перейти на страницу, дождаться полной подгрузки элементов с селектором .product-card.\n3. Прокрутить страницу вниз для срабатывания ленивой загрузки (Lazy Loading).\n4. Собрать тексты элементов и сохранить в файл data.json.`

---

### Шаг 4. Анализ собранных данных прямо в консоли
После завершения парсинга попросите Claude Code обработать полученный CSV/JSON файл.

Промпт для аналитики данных:
`Прочитай файл products.csv с помощью библиотеки pandas. Найди 5 товаров с наибольшей скидкой в процентах и рассчитай среднюю цену товара по всей категории. Сформируй сводную таблицу.`

## Примеры

### Пример 1. Выгрузка новостных заголовков с пагинацией за 2 минуты
**Запрос пользователей в Claude Code:**
`Напиши скрипт, который проходит по 3 страницам новостного сайта (url/news?page=1, page=2, page=3), извлекает заголовки статей и даты публикации, и сохраняет их в табличный файл news_export.xlsx.`

**Действие Claude Code:**
ИИ создает скрипт `parse_news.py`, обрабатывает циклы пагинации, подключает библиотеку `openpyxl` и генерирует готовую таблицу `news_export.xlsx`.

---

### Пример 2. Извлечение скрытого JSON API из сетевых запросов
**Запрос пользователей:**
`Найди внутри HTML-кода страницы тег <script id="__NEXT_DATA__">, распарси его JSON-содержимое и извлеки массив категорий товаров в файл categories.json.`

**Результат:** Claude Code автоматически извлекает внутреннее состояние одностраничного приложения (SPA) без необходимости сложной верстки парсера DOM.

## Частые ошибки и вопросы

**Вопрос 1: Что делать, если сайт блокирует парсер по IP-адресу или возвращает ошибку 403 Forbidden?**
*Ответ:* Добавьте ротацию заголовков `User-Agent`, используйте прокси-серверы и увеличивайте задержку между запросами. Попросите Claude Code: *\"Добавь в parser.py поддержку списков прокси из файла proxies.txt\"*.

**Вопрос 2: В чем преимущество создания парсеров через Claude Code по сравнению со сторонними ноу-код сервисами?**
*Ответ:* Скрипты на Python/Node.js полностью принадлежат вам, работают без ограничений по тарифным планам, легко кастомизируются под любую логику и могут быть запущены на любом сервере в автоматическом режиме через `cron`.

**Вопрос 3: Как спарсить данные, если сайт требует авторизации под логином и паролем?**
*Ответ:* Попросите Claude Code добавить авторизацию через сессии `requests.Session()` или сохранить куки (Cookies) после ручного входа через браузер Playwright.

**Вопрос 4: Является ли парсинг открытых данных законным?**
*Ответ:* Соблюдайте файл `robots.txt` сайта, не совершайте слишком частых запросов, создающих нагрузки на сервер (DDoS-эффект), и используйте только публично доступные данные.

**Вопрос 5: Сколько времени занимает создание и запуск простого парсера в Claude Code?**
*Ответ:* От отправки промпта до готового файла CSV с данными проходит от 2 до 4 минут.
