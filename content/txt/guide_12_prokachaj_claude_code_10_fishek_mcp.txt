# Прокачай Claude Code за 10 мин | 10 фишек + MCP

## Зачем это нужно
Многие разработчики используют Claude Code как простой чат-бот для генерации кусков кода, упуская до 70% его реальных возможностей. Инструмент содержит встроенные скрытые функции, слэш-команды и протокол расширения MCP (Model Context Protocol), которые позволяют подключать сторонние базы данных, внешние API, системы управления задачами и выполнять сложные автономные сценарии. Этот гайд содержит 10 практических приемов по повышению эффективности работы в Claude Code и разбор настройки первого MCP-сервера за 10 минут.

## Что внутри
* Инструкция по быстрой базовой установке утилиты.
* Разбор 10 скрытых приемов ускорения разработки в Claude Code.
* Понятное объяснение принципа работы протокола MCP (Model Context Protocol).
* Пошаговый процесс подключения внешнего MCP-сервера через конфиг `.mcp.json` и консоль.
* Практический пример использования MCP для работы с базой данных PostgreSQL или GitHub.
* Ответы на частые вопросы по безопасности и производительности.

## Пошаговая инструкция

### Шаг 1. Проверка окружения Claude Code
1. **Установка на Windows через PowerShell:**
   `irm https://claude.ai/install.ps1 | iex`
2. **Установка через npm (Node.js 22+):**
   `npm install -g @anthropic-ai/claude-code`
3. **Проверка работы:**
   `claude --version`

### Шаг 2. 10 Практических фишек работы в Claude Code

1. **Быстрый просмотр и очистка контекста (`/compact` и `/clear`):**
   Если диалог стал слишком длинным, команда `/compact` сжимает историю общения без потери ключевых фактов, а `/clear` полностью очищает контекст для новой задачи.
2. **Управление авто-памятью проекта (`/memory`):**
   Используйте команда `/memory` для быстрого просмотра и вычистки накопленных ассистентом заметок о проекте.
3. **Параллельная генерация и проверка тестов:**
   Попросите ИИ запустить тесты в терминале и сразу исправить упавшие сценарии без вашего вмешательства.
4. **Передача конкретных файлов через сопоставление путей:**
   Используйте относительные пути для точного направления ассистента на нужные файлы.
5. **Мульти-строчные промпты в консоли:**
   Используйте комбинации клавиш для ввода развернутых структурированных инструкций.
6. **Автоматический рефакторинг по линтеру:**
   Отправьте команду `Запусти npm run lint и исправь все автоматически исправляемые ошибки`.
7. **Генерация Git-коммитов по изменениям:**
   Попросите `Проанализируй git diff и сформируй коммит в стиле Conventional Commits`.
8. **Поиск уязвимостей в зависимостях:**
   Попросите ИИ проанализировать `package.json` или `requirements.txt` на наличие устаревших пакетов.
9. **Автоматическое создание файлов документации:**
   Генерируйте файлы `README.md` на основе вызова и анализа структуры модулей.
10. **Режим автономного выполнения команд:**
    Разрешайте безопасное выполнение команд просмотра директорий и чтения файлов без подтверждения каждого шага.

---

### Шаг 3. Подключение внешних инструментов через MCP (Model Context Protocol)
MCP — это открытый протокол, позволяющий Claude Code подключаться к внешним источникам данных: базам данных, сервисам мониторинга, GitHub, Figma и таск-трекерам.

1. **Добавление MCP-сервера через консольную команду:**
   Для добавления нового MCP-сервера выполните команду:
   `claude mcp add`

2. **Ручная настройка через файл `.mcp.json`:**
   В корне проекта или в домашней директории создайте файл `.mcp.json` со следующей структурой:

```json
{
  "mcpServers": {
    "postgres-db": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-postgres",
        "postgresql://user:password@localhost:5432/my_database"
      ]
    }
  }
}
```

3. **Использование MCP на практике:**
   После перезапуска сессии Claude Code получит новые инструменты и сможет напрямую выполнять SQL-запросы к вашей БД, анализировать таблицы и писать миграции.

## Примеры

### Пример 1. Автоматический анализ схемы базы данных через MCP
**Запрос разработчика в консоли:**
`Считай схему таблицы users из базы данных PostgreSQL через подключенный MCP-сервер и напиши модель SQLAlchemy на Python для этой таблицы.`

**Действие Claude Code:**
Ассистент вызывает инструмент MCP, считывает столбцы таблицы `users` из реальной базы данных и моментально выдает корректный Python-код с совпадением всех типов полей.

### Пример 2. Автоматическое исправление упавшего теста
**Запрос разработчика:**
`Запусти pytest. Если есть упавшие тесты, прочитай их логи, найди ошибку в коде и исправь её.`

**Действие Claude Code:**
Ассистент выполняет команду тестирования в терминале, перехватывает трассировку ошибки, открывает проблемный файл, исправляет баг и повторно запускает тесты до получения успешного статуса.

## Частые ошибки и вопросы

**Вопрос 1: Безопасно ли передавать пароль от базы данных в файл .mcp.json?**
*Ответ:* Не храните пароли в открытом виде в Git-репозитории. Добавляйте файл `.mcp.json` в `.gitignore` или используйте ссылки на переменные окружения вашей системы.

**Вопрос 2: Где найти готовые MCP-серверы для интеграции с популярными сервисами?**
*Ответ:* Официальные и сообщественные MCP-серверы доступны в репозиториях открытого кода (GitHub) для PostgreSQL, SQLite, GitHub, Brave Search, Slack и многих других систем.

**Вопрос 3: Замедляет ли подключение нескольких MCP-серверов работу Claude Code?**
*Ответ:* Каждое подключение добавляет в контекст описания доступных инструментов. Подключайте только те MCP-серверы, которые реально нужны для решения текущей задачи.

**Вопрос 4: Что делать, если MCP-сервер не откликается?**
*Ответ:* Проверьте наличие установленной Node.js (версии 22+), доступность командного окружения и корректность сетевого адреса подключения.

**Вопрос 5: Сколько времени занимает первичная настройка MCP?**
*Ответ:* При наличии готовой команды или шаблона `.mcp.json` процедура подключения занимает не более 2-3 минут.
