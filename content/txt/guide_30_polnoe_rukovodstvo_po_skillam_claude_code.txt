# Полное руководство по скиллам Claude Code: Расширение возможностей ИИ

## Зачем это нужно
Разработчики регулярно сталкиваются со сложными узкоспециализированными рабочими процессами: проведением аудита доступности (a11y), глубокой проверкой безопасности по стандартам OWASP, форматированием спецификаций API или версткой по строгому дизайн-макету. Каждый раз вписывать огромные текстовые инструкции в промпты неудобно и приводит к размыванию контекста. Механизм скиллов (Skills) в Claude Code решает эту проблему. Скиллы — это подключаемые папки с инструкциями, шаблонами и вспомогательными скриптами, организованные вокруг файла `SKILL.md`. Инструмент считывает скиллы по требованию и выполняет профильные задачи на профессиональном уровне. Этот гайд содержит руководство по созданию, структурированию и активации скиллов.

## Что внутри
* Понимание концепции скиллов (Skills) в Claude Code и отличие от память-файлов `CLAUDE.md`.
* Структура папки скилла: файл `SKILL.md`, YAML-заголовок (Frontmatter) и допфайлы.
* Расположение глобальных и проектных скиллов (`.agents/skills/`).
* Инструкция по созданию собственного скилла с шагами и правилами.
* Примеры 3 готовых практических скиллов: `code-auditor`, `api-designer`, `tailwind-styler`.
* Разбор практического применения скилла для рефакторинга кода.
* Ответы на частые вопросы по вызову скиллов и отладке их исполнения.

## Пошаговая инструкция

### Шаг 1. Понимание архитектуры и структуры скилла (Skill Structure)
Скилл представляет собой отдельную директорию с файлом `SKILL.md`, который содержит служебную метаинформацию (YAML frontmatter) и подробную markdown-инструкцию для ассистента.

Стандартная структура папки скилла:
```
my-custom-skill/
├── SKILL.md                 # Главный файл с метаданными и инструкцией
├── scripts/                 # Вспомогательные скрипты (Bash, Python)
├── templates/               # Шаблоны файлов (JSON, HTML, YAML)
└── references/              # Дополнительная справка и стандарт
```

---

### Шаг 2. Создание файла `SKILL.md` с YAML-метаданными
Заголовок файла `SKILL.md` обязательно содержит поля `name` и `description`, по которым Claude Code понимает назначение скилла.

Пример содержимого `SKILL.md`:
```markdown
---
name: security-audit-expert
description: Экспертный скилл по аудиту уязвимостей репозитория на основе стандартов OWASP Top 10
---

# Инструкция скилла по аудиту безопасности

Твоя задача — проводить глубокий анализ безопасности исходного кода.

## Чек-лист проверки:
1. Поищи неизолированные SQL-запросы (SQL Injection).
2. Проверь санитайзинг пользовательского ввода для предотвращения XSS.
3. Проверь хранение секретов и API-ключей (не должно быть в коде).
4. Проверь настройки CORS в конфигурационных файлах.

## Формат отчета:
Сформируй таблицу [№, Уязвимость, Файл и строка, Уровень риска (CRITICAL/HIGH/MEDIUM), Исправление].
```

---

### Шаг 3. Размещение скиллов в проекте или глобальном профиле
Claude Code автоматически сканирует скиллы из двух основных директорий:

1. **Проектные скиллы (Project Skills):**
   Сохраните папку скилла по пути: `.agents/skills/название_скилла/SKILL.md` в корне вашего репозитория. Скилл будет доступен всем разработчикам этого проекта.
2. **Глобальные скиллы (Global Skills):**
   Сохраните папку скилла в пользовательском профиле настроек для использования во всех ваших проектах.

---

### Шаг 4. Вызов и активация скилла в сессии
Вы можете активировать скилл явным образом или положить задачу, соответствующую описанию (`description`) скилла:

1. **Явный вызов:**
   `Примени скилл security-audit-expert для проверки папки /src/auth.`
2. **Автоматическая активация:**
   Когда вы просите Claude Code *"Проверь код на уязвимости OWASP"*, инструмент самостоятельно считывает файл `SKILL.md` скилла `security-audit-expert` и выполняет инструкцию.

## Примеры

### Пример 1. Скилл `api-designer` для создания OpenAPI 3.0 спецификаций
**Файл `SKILL.md`:**
```markdown
---
name: api-designer
description: Проектирование REST API спецификаций в формате OpenAPI 3.0 (YAML)
---
# Спецификация REST API
Создавай валидные OpenAPI 3.0 схемы в формате YAML. Обязательно указывай схемы ответов 200, 400, 401, 500 и типы данных Pydantic / TypeScript.
```

**Результат использования:** Разработчик пишет: `Составь API для модуля оплаты`, и Claude Code генерирует строгий валидный YAML-файл OpenAPI без лишних уточнений.

---

### Пример 2. Скилл `tailwind-styler` для конвертации стилей
**Запрос пользователя:** `Примени скилл tailwind-styler и перепиши этот чистый CSS-файл в утилитарные классы TailwindCSS в компоненте React`.

## Частые ошибки и вопросы

**Вопрос 1: В чем разница между `CLAUDE.md` и Скиллами (Skills)?**
*Ответ:* Файл `CLAUDE.md` содержит краткие общие правила для ВСЕГО проекта (стиль кода, команды сборки) и загружается в начале КАЖДОЙ сессии. Скиллы (`SKILL.md`) — это объемные узкоспециализированные инструкции, которые подгружаются ТОЛЬКО тогда, когда решается конкретная задача.

**Вопрос 2: Могут ли скиллы содержать исполняемые скрипты?**
*Ответ:* Да. Внутри папки скилла можно размещать скрипты на Python или Bash, которые Claude Code сможет запускать при выполнении скилла.

**Вопрос 3: Как обновить или переписать имеющийся скилл?**
*Ответ:* Просто отредактируйте текст в файле `SKILL.md`. Изменения вступают в силу немедленно при следующем вызове скилла.

**Вопрос 4: Как поделиться скиллом с командой разработки?**
*Ответ:* Закоммитьте папку `.agents/skills/имя_скилла/` в Git-репозиторий проекта. Все члены команды получат доступ к скиллу автоматически после `git pull`.

**Вопрос 5: Сколько скиллов можно подключить к одному проекту?**
*Ответ:* Ограничений на количество скиллов нет. Модульная структура позволяет хранить десятки профильных скиллов под любые задачи разработки.
